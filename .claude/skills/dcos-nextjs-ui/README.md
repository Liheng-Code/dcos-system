# dcos-nextjs-ui

Claude Code skill for designing and implementing the Digital Construction Operating System UI using Next.js, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Install

Copy this folder to:

```text
.claude/skills/dcos-nextjs-ui/
```

## Use Cases

Use this skill when asking Claude Code to:

- Design DCOS dashboard layouts
- Build WBS/task workspaces
- Create task, document, stakeholder, project setup forms
- Generate shadcn/ui components
- Design role-aware construction workflows
- Create tables, filters, drawers, approval timelines, and activity logs

## Core Principle

Project context first, WBS context second, module workflow third, action and approval state always visible.
