# DCOS Documentation Skill

This Claude Code skill helps create professional markdown documentation for the Digital Construction Operating System (DCOS).

## Install

Copy this folder to:

```text
.claude/skills/dcos-documentation/
```

## Main Use Cases

- Module specifications
- Implementation prompts
- Architecture documents
- Workflow documents
- Database design notes
- Gap analysis reports
- README files
- Developer handover documents

## Example Requests

```text
Use the dcos-documentation skill to create a module specification for Project Setup.
```

```text
Use the dcos-documentation skill to rewrite this workflow as an implementation-ready markdown prompt.
```

```text
Use the dcos-documentation skill to upgrade this document from R1 to R2 with missing data model, permissions, notifications, and audit rules.
```
