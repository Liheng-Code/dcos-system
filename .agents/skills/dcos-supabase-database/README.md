# dcos-supabase-database

Claude Code skill for designing and reviewing the Supabase/PostgreSQL database layer of DCOS.

## Install

Copy this folder to:

```text
.claude/skills/dcos-supabase-database/
```

## Use

Example prompt:

```text
Use the dcos-supabase-database skill.
Design the database tables for the DCOS Task Management module.
Include SQL migration, RLS policies, indexes, seed data, audit log integration, and links to project_id and wbs_node_id.
```

## Best For

- Supabase SQL migrations
- PostgreSQL schema design
- Row Level Security policies
- Multi-tenant database rules
- WBS-linked construction data
- Audit log and notification integration
- Seed data for DCOS modules
