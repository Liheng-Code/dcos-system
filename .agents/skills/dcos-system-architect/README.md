# dcos-system-architect

Claude Code skill for designing and reviewing the Digital Construction Operating System (DCOS).

## Install

Copy this folder into your project:

```text
.claude/skills/dcos-system-architect/
```

Final structure:

```text
.claude/
└── skills/
    └── dcos-system-architect/
        ├── skill.md
        └── README.md
```

## Use

Ask Claude Code:

```text
Use the dcos-system-architect skill to design the Project Setup module.
```

or

```text
Use the dcos-system-architect skill to review this database schema for DCOS.
```

## Best Use Cases

- DCOS module design
- WBS architecture review
- Database schema planning
- RBAC and permission design
- Approval workflow design
- Audit log and notification design
- MVP phasing
- Construction workflow validation
