# DCOS Audit Notification Skill

Claude Code skill for designing the DCOS Audit Trail Engine and Notification Matrix Engine.

## Install

Copy this folder to:

```text
.claude/skills/dcos-audit-notification/
```

## Use Cases

Ask Claude Code things like:

```text
Use dcos-audit-notification skill to design audit and notification rules for task approval workflow.
```

```text
Use dcos-audit-notification skill to create Supabase tables for notifications and audit logs.
```

```text
Use dcos-audit-notification skill to design notification matrix for RFI, NCR, PR, PO, and safety incidents.
```

## Scope

This skill covers:

- Audit log data model
- Notification templates
- Notification rules
- Notification delivery logs
- Escalation logic
- Anti-spam rules
- Activity timeline
- Supabase RLS guidance
- Test case patterns
