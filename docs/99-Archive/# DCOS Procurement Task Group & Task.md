## DCOS Best Practice Recommendation

For maximum automation, each **Procurement Task Template** should also include:

* Default Duration (Days)
* Predecessor & Successor Tasks
* Responsible Role
* Required Deliverables
* Required Approval Workflow
* Required Attachments
* Procurement Package Link
* BOQ Item Link
* Cost Code Link
* Supplier Link
* Notification Rules
* SLA Due Date
* Risk Level
* KPI Weight
* Auto-generated Checklist

With this design, selecting a Procurement Package such as **"Concrete Supply"**, **"Curtain Wall"**, or **"Elevator System"** can automatically generate the complete procurement workflow from **MR → PR → RFQ → Evaluation → PO → Delivery → GRN → Invoice → Contract Closeout**, making DCOS behave like a true enterprise construction ERP platform.
