# DCOS Architecture Task Group & Task Template Library

## Digital Construction Operating System (DCOS)

**Purpose:** Standard reusable task templates for all building projects

This library can be directly mapped to the DCOS Project Generator. When an Architecture discipline is assigned to a WBS node (Building, Level, Room, or Element), the selected Task Groups and their corresponding tasks can be automatically instantiated, eliminating repetitive manual task creation while maintaining a consistent company standard.
