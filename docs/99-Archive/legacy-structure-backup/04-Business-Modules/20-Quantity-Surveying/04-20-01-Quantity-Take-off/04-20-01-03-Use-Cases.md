# 03 – Use Cases  
**Module:** 04-20-01 Quantity Take-off

## UC-01: Create New Take-off Session
**Actor:** Quantity Surveyor  
**Precondition:** User has access to the project and drawing exists  
**Main Flow:**
1. User navigates to Quantity Take-off
2. Clicks “New Session”
3. Selects Project → Drawing → Revision
4. Enters Session Name and Trade
5. System creates session in Draft status
**Postcondition:** Session is ready for measurement

## UC-02: Perform Manual Take-off
**Actor:** Quantity Surveyor  
**Main Flow:**
1. Open existing session
2. Select measurement tool (Length/Area/Volume/Count)
3. Measure on drawing
4. Enter description and apply factors
5. Assign Cost Code, WBS, Location
6. Save item

## UC-03: Compare Two Revisions
**Actor:** Senior QS  
**Main Flow:**
1. Select two completed sessions of the same drawing
2. System shows side-by-side comparison
3. Variance is calculated automatically
4. User can export comparison report

## UC-04: Push Quantities to Cost Estimation
**Actor:** Quantity Surveyor  
**Main Flow:**
1. Open completed session
2. Click “Push to Cost Estimation”
3. Select target estimate version
4. System transfers all firm quantities
