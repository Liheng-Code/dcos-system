# 01-Master-Data-Standards

Single source of truth for all enterprise classifications, master data governance, coding conventions, and cost rate standards.

---

## 📂 Subdirectories

### 1. [`mdm/`](./mdm/) — Master Data Management Governance
* **Standards**: `DCOS-MDM-STD-001` Enterprise Master Data Standard.
* **Catalogues**: `DCOS-MDM-CAT-001` Master Data Catalogue.
* **Coding**: `DCOS-MDM-COD-001` Master Data Coding & Naming Standard.
* **Decisions**: Architectural Decision Records (ADRs) for canonical identity and business codes.

### 2. [`naming-conventions/`](./naming-conventions/) — System-wide Naming Conventions
* Standard Operating Procedures (SOP) for naming projects, tasks, drawings, and documents.
* Running number allocations and code generators.
