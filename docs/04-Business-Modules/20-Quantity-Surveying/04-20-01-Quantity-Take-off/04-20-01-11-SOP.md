# 11 – Standard Operating Procedure
**Module:** 04-20-01 Quantity Take-off
**Version:** 1.1 (as built, P0)

## 1. Before you measure
1. Register the drawing and upload each revision as a PDF on **Quantity Take-off › Drawings**.
2. Check that the approved company ruleset you need exists under **Measurement Rules**.

## 2. Create a session
1. **Sessions › New session.**
2. Pick the drawing and the **exact revision**. The system never swaps in the latest one.
3. Pick the approved ruleset version.
4. Name it "[Trade] – [Drawing No] – Rev [X]" (suggested automatically).
5. Review the summary and create it. It starts as version 1, Draft. Press **Start measuring**.

## 3. Measure
1. **Calibrate every page first.** Choose **Scale**, click both ends of a printed dimension, and enter its real length. The scale is saved for that revision and page.
2. Select an item, or none to create one, then measure with Length, Polyline, Area, Perimeter or Count:
   - **Enter** finishes, **Backspace** removes the last point, **Esc** cancels.
   - Each measurement is saved to the item as evidence.
3. In the item panel:
   - Choose the **measurement rule** and fill the inputs ("use …" copies a measurement).
   - Add **deductions** for openings and voids according to the rule's policy.
   - Apply only the **factors the ruleset authorises**.
   - **Record calculation.** Nothing is applied silently; the result shows gross, deductions, net, factors and rounding.
4. Classify each item:
   - Work section (required), element, building, level and zone.
   - WBS and budget code.
   - The tender BOQ line it should feed, if one already exists.
5. Set the quantity status:
   - **Firm** for complete information.
   - **Provisional**, with the assumption written down.
   - **Excluded**, with the reason.
   - **Pending clarification** while an RFI is open.

## 4. Check and submit
1. Press **Validate**.
2. Fix every **blocking** issue.
3. Each **warning** needs a fix, or an acknowledgement with a written justification.
4. **Submit for review.** The version becomes read-only.

## 5. Review, publish, transfer (reviewer)
1. Open the session, inspect the items, calculations, evidence and **Changes** against the baseline.
2. **Approve**, or **Request changes** with a comment. You cannot approve a version you submitted.
3. **Publish.** The approved version is frozen in a snapshot with an integrity hash; this is the quantity baseline.
4. **Transfer to BOQ:**
   - Confirm the target tender.
   - Decide whether provisional items go too.
   - Allow overwriting only if a BOQ line was deliberately changed outside take-off.
   - A failed transfer changes nothing and can be retried.
5. **Excel / CSV** exports always come from the published snapshot.

## 6. When drawings change
1. On the session, press **New version**. Give the reason, choose the new revision, and pick the items to carry forward.
2. **Revalidate each carried item:** marked "unverified", it must be remeasured or confirmed as unchanged before submission (warning).
3. Use **Changes vs vN** to see added, removed, increased and decreased items and the variance.

## 7. Rules for everyone
- Never delete items permanently. Removing an item keeps it in the audit history; only an administrator can hard-delete.
- Every change, decision, publication, transfer and export is logged.
