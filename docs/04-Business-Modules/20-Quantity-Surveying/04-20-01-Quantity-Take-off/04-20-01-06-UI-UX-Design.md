# 06 – UI/UX Design  
**Module:** 04-20-01 Quantity Take-off

## Screen List
1. Take-off Dashboard
2. Create / Edit Session
3. Measurement Workspace (Core screen)
4. Item Detail Drawer
5. Quantity Summary (Pivot)
6. Revision Comparison
7. Export & Push Modal

## Measurement Workspace Layout
- Left 70%: Drawing / Model Viewer with measurement tools
- Right 30%: Item list + quick add form
- Top bar: Session info + status + progress
- Bottom bar: Running totals by unit

## Design Principles
- Keyboard-first for high-speed measurement
- Auto-save every 30 seconds
- Clear Provisional vs Firm visual distinction
- Colour coding by Trade
- Minimal clicks to complete common tasks
