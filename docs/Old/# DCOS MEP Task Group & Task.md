# DCOS MEP Task Group & Task Template Library

## Digital Construction Operating System (DCOS)

**Module:** MEP Task Template Library
**Discipline:** Mechanical, Electrical & Plumbing (MEP)
**Purpose:** Standard reusable task templates for MEP design, procurement support, BIM coordination, construction support, testing, commissioning, and handover.

## Total Standard MEP Tasks

**Total Task Groups:** 15
**Total Standard Tasks:** **152 Tasks**

This MEP Task Template Library is designed to integrate directly with the DCOS WBS and Project Generator. When the MEP discipline is assigned to a Building, Level, Zone, Room, or Element, the system can automatically generate all applicable task groups, dependencies, deliverables, approval workflows, and responsible roles, providing a standardized execution framework for every project.
