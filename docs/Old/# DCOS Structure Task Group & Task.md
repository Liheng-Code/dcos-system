# DCOS Structure Task Group & Task Template Library

## Digital Construction Operating System (DCOS)

**Module:** Structure Task Template Library (STR)
**Discipline:** Structural Engineering
**Purpose:** Standard reusable task templates for structural design, coordination, procurement support, construction support, QA/QC, and handover.

## Total Standard Structure Tasks

**Total Task Groups:** 15
**Total Standard Tasks:** **148 Tasks**

This library is intended to be linked to the DCOS WBS Generator. When a Structural discipline is assigned to a Building, Level, Zone, Room, or Element, the corresponding Task Groups and Tasks can be instantiated automatically, together with default durations, predecessors, deliverables, approval workflows, and responsible roles, eliminating repetitive manual task creation while ensuring company-wide standardization.
