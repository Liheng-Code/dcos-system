🧩 PHASE 1

✨ Sequential wizard design

The wizard follows a logical project build-up: from Basic Info → Contract → Stakeholders → Team → Calendar → WBS → Numbering → Approval flows → Budget → Notifications → Activation.

5CalendarWorking days, holidays
6WBSTemplate / Manual / Import
7NumberingDoc format, discipline
8ApprovalDrawing, RFI, PR flows
9BudgetContract value, limits
10NotificationTelegram + in-app rules
11ActivateValidation checklist
⚙️ Each step is isolated, data is persisted before final activation. React motion transitions ensure smooth navigation.

"Create once, reuse across projects"
🖼️ Middle panel: Structure preview

List all placeholders (Owner, Consultant, Contractor). Each holds team templates (Design Review, Construction Team). Admins can edit inline.

Final mapping of placeholder → real companies. After “Apply Template”, data transforms into project-linked stakeholder groups, synced with user directory.

🔍 Implementation note: The component uses useState to manage selected template, selectedCompanyIndex, and dynamically renders teams. Mapping changes, company selection and permission preview — all built to maintain clean separation between master templates and runtime project data.

🖥️ UI Layout: Project Register + Setup Wizard + Summary Panel

📋 Left panel: Project Register
  • Table of projects (code, name, status)
  • Search & filtering, row selection updates active step context
  • Total projects / Active / Tender metrics
⚙️ Center: Wizard Steps
  • Dynamic step buttons with icons (completed/done/in progress)
  • motion animation sliding between steps
  • Step-specific content (Basic info, contract, stakeholder template, etc)
📊 Right: Setup Summary
  • Current project card with completion % bar
  • Validation checklist (real-time status)
  • Activation and report buttons
💡 Assignment flow summary:
1. Project manager selects project from register → 2. Navigates through wizard steps (Basic info → contract) → 3. In stakeholder step, choose pre-defined template & map actual companies/teams. 4. Configure team members, WBS, numbering rules, budget, approval workflows. 5. Validation checklist updates automatically as steps are completed. 6. Once all criteria met, Activate Project button becomes enabled → project moves to “Active” state within the register.
