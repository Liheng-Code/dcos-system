# 03-Operations-SOP — DCOS Standard Operating Procedures

> **Standard Operating Procedures (SOPs), Administrative Policies & Field Guides**

This directory contains the operational guidelines and procedures for project delivery, administrative governance, and system operations.

---

## 📂 Active SOP Modules

| Code | SOP Domain | Key Documents & Guides |
|---|---|---|
| **SOP-01** | **User Management** | User onboarding, RBAC roles, permission assignments, profile statuses |
| **SOP-02** | **Stakeholder Management** | Stakeholder registration, vendor tiers, project mappings, staff contacts |
| **SOP-03** | **Project Setup** | Project blueprints, pre-contract vs. post-contract transitions, site parameters |
| **SOP-04** | **WBS Management** | WBS Spine standards, hierarchical code structures, template applications |
| **SOP-05** | **Task Management** | Activity tracking, progress updates, task alert workflows |
| **SOP-06** | **Planning & Scheduling** | `SOP-PLN-001` CPM scheduling, calendar management, productivity tracking |
| **SOP-22** | **Quantity Surveying** | `SOP-QS-Module` Rate libraries, BOQ preparation, progress claim valuation |

---

## 📋 Governance & Change Control
* Review cycles: SOPs are maintained alongside codebase module updates.
* Change requests: Every change to a SOP must be reflected in the respective business module specification (`docs/02-Modules/`).
